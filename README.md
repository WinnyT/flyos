## Features

`Georgia` — Opens the main FlyOS window

`California` — Generates a random lucky number from 1 to 99

`Texas` — Opens a video player with a Texas-themed clip

`Washington, D.C.` — Opens an audio player for the American national anthem

* Draggable windows inspired by desktop operating systems
* macOS-style red close buttons
* Different interactions hidden around the map
* Random mini apps and Easter eggs depending on where you click
* Built to feel like a tiny chaotic internet operating system

## How to run it locally

Requirements:

* A web browser
* Git

### Setup

Clone the repository:

```bash
git clone https://github.com/WinnyT/flyos.git
cd flyos
```

Open `index.html` in your browser.

Or start a local server:

```bash
python3 -m http.server
```

Then open:

```text
http://localhost:8000
```

## Permissions

FlyOS does not require any special browser permissions.

All interactions run directly in the browser using HTML, CSS, and JavaScript.

FlyOS is hosted using GitHub Pages so anyone can open and explore it in their browser.
